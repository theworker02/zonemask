# zonemask

Zone config/mask key checks for twelve-factor services.

**Site:** https://theworker02.github.io/zonemask/

## Install / run

```bash
git clone https://github.com/theworker02/zonemask.git
cd zonemask
node src/cli.js
node --test
```
